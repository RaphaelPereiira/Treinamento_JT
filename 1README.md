O media.js é um exercício em JavaScript que calcula a média de quatro notas e informa se o aluno foi aprovado ou reprovado. O programa roda no terminal com Node.js e usa o prompt-sync para receber as respostas.

Como funciona:

1. O programa solicita o nome do aluno e as quatro notas.
2. Cada nota deve estar entre 0 e 10. É possível digitar decimais com vírgula ou ponto, como `7,5` ou `7.5`. Se a nota for inválida, o programa pede o valor novamente.
3. A média é calculada somando as quatro notas e dividindo o total por 4.
4. O programa exibe o nome, a média com duas casas decimais e o resultado final.
5. Igual ou superior a 7 deve ser aprovado.
6. Inferior a 7 deve ser reprovado.

A decisão usa a média calculada antes da formatação para duas casas decimais.
